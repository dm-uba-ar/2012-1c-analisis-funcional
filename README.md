# **REGIMEN DE APROBACION DE LA MATERIA**

\
- **Régimen de promoción**.
  Para firmar los trabajos prácticos se deben aprobar
  dos exámenes parciales. Habrá dos fechas de recuperación, una para cada parcial. En el primer recuperatorio se evaluarán los contenidos que entraron para el primer parcial. En la segunda instancia de recuperación se evaluarán los contenidos que entraron para el segundo parcial.
- **Inscripción**. Para poder ser incluido en las Actas,
  en caso de aprobar los trabajos prácticos, es necesario haberse
  inscripto en la materia (a través del
  [Sistema de Inscripciones de la Facultad](http://www.inscripciones.fcen.uba.ar/))
  y haber completado la encuesta de evaluación docente.
